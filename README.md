## 🛠️ Instalación y Desarrollo Local

```bash
# Clonar el repositorio
git clone https://github.com/Santiago04-web/FUNDACION-EMPRESAS-PUBLICAS-DE-MEDELLIN.git

# Entrar al directorio
cd FUNDACION-EMPRESAS-PUBLICAS-DE-MEDELLIN

# Instalar dependencias
npm install

# Iniciar servidor de desarrollo
npm run dev

# Compilar para producción
npm run build
```
